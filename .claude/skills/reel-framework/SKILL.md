# Reel framework (master pacing structure)

Learned from kierzacporter (Porter Productions), shared by the user as the proven framework for engaging people who are already interested in your topic. Screenshot: `references/framework-screenshot.png`.

## The beats, in order

| Beat | Job | Plain meaning |
|------|-----|---------------|
| Hook | The feeling that stops them | First line. Make the viewer feel something specific, not just hear a topic. |
| Super hook | Earn the right to teach | Show why you are credible or why this matters to them, fast. |
| Open loop | Commit them to the end | Promise something that only pays off at the finish. |
| Body 1 | Deliver real value | A real point, not filler. |
| Rehook | "Okay, one more" | A line that makes the viewer stay for the next point. |
| Body 2 | Deliver real value | |
| Rehook | "Okay, one more" | |
| Body 3 | Deliver real value | |
| Payoff / CTA | Close the loop, better than promised | Pay off the open loop, then one clear call to action. |

Three bodies with a rehook between each is the default. Cut to two bodies for a 30 second reel, never drop the open loop or the payoff.

## How to use it

- **Scripting:** write the open loop and payoff first, then the bodies, then the hook last.
- **Editing a raw take:** find these beats in the transcript. If a beat is missing, say so and suggest a line to record or a graphic that carries it.
- **Graphics and B-roll:** change the visual on every beat boundary, and re-engage with a visual at every rehook. Put the biggest motion graphic on the payoff.
- **Pacing:** no dead air, a new visual or line every 3-5 seconds, and the loop stays open until the payoff.
- **Review:** list each beat with its timestamp and flag any that is weak or missing.

Pair with `content-principles` (the psychology), `humanizer` (wording), `caption-engine` (post captions) and `video-editing` / HyperFrames / Remotion (rendering). Style references: `research/reel-styles.md`.
